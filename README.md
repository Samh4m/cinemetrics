# CineMetrics

A data engineering portfolio project building an end-to-end pipeline for movie and TV analytics. Ingests data from public APIs (TMDB), transforms it via dbt, and exposes business metrics through a dashboard.

## Status

Under construction — V1 (local pipeline).

## Stack

- **Ingestion:** Python (`requests`, `httpx`)
- **Storage:** DuckDB (V1) → BigQuery (V3)
- **Transformation:** dbt Core
- **Orchestration:** Dagster (V2)
- **Dashboard:** Streamlit (V2)
- **Infra:** Docker + GCP (V3)
